# Iznajmljivanje studija

Aplikacija za iznajmljivanje studija, razvijena u okviru projekta iz predmeta Projektovanje Softvera.

## Opis projekta

Cilj projekta je razvoj aplikacije koja omogućava upravljanje procesom iznajmljivanja studija. Projekat je realizovan u C# jeziku.

## Tehnologije

- C#
- .NET
- Windows Forms
- SQL baza podataka

## Struktura projekta

- `Common` – zajedničke klase i komponente
- `DBBroker` – komunikacija sa bazom podataka
- `Forme` – korisnički interfejs
- `Server` – serverski deo aplikacije
- `SistemskeOperacije` – poslovna logika i sistemske operacije

## Pokretanje projekta

1. Klonirati repozitorijum.
2. Otvoriti solution fajl u Visual Studio okruženju.
3. Podesiti konekciju sa bazom podataka, ukoliko je potrebno.
4. Pokrenuti aplikaciju.
